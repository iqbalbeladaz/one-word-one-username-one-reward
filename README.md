## The entry

> ibalee

One word, 6 characters (gate: 1–30, single word) — the entrant's own
make.fun username, @ibalee, and nothing else.

## Why this username should win

- **A real make.fun username:** it is the entrant's own handle, sent as one
  word — the first thing the judge weighs, and the one criterion that beats
  any invented word.
- **Raises a smile on first read:** say it aloud and it sounds like a
  friendly introduction — "I, Balee" — a name that greets the judge before
  the judge reads it.
- **Sticks after one look:** the short "i" up front and the soft double-e
  landing at the end give it a rhythm of its own; it is easy to remember
  and hard to confuse with anything else.
- **A single word, no padding:** no spaces, no gloss, no pitch tacked on —
  the username is the whole entry, exactly as the bounty asks.
- **A handle its owner would happily wear:** warm and personal, not a jab
  at anybody — a name that belongs on a profile, not on a punchline.

## How it works

`main.py` writes the username to `/output/entry.txt`. It is fully
deterministic: the same bytes on every run, no input, no randomness, no
network. The program refuses to write anything that would fail the gate
(1–30 characters, not only white space, a single word of letters).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
